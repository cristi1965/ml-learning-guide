# 从苹果到 GPT

基于 [samitmohan/ML](https://github.com/samitmohan/ML) 的中文学习导读。16节核心课程，包含分步动画、交互实验、小测、中文注释源码节选和浏览器本地学习记录。

## 使用

直接打开 `course.html`，或用静态服务器提供本目录。手机支持大字阅读、底部课程导航、目录抽屉和代码自动换行。动画支持播放、暂停和手动逐步查看，不自动播放。

每课引用固定提交的原作者源码；原始代码归原作者，新增中文注释与教学内容已明确区分。节选不是独立运行程序，完整上下文请访问课内源码链接。此仓库没有对上游代码重新授权。

本课程为核心概念导读，不是逐文件完整教材。网页不执行Python。小测通过不代表实操或泛化验证完成。

笔记与进度存储在当前浏览器，不上传服务器，不跨设备同步。导出JSON用于离线留存，暂不支持导入恢复。从本地文件迁移到Pages后，两处记录不会自动互通。

部署使用 `gh-pages` 根目录和 `.nojekyll`，无构建步骤。
